# Relational Repertoire demos

Four English fictional case studies by Pedro Portela, using the same episode-based relational repertoire framework.

- Innovation: https://pportela1980.github.io/networks/relational-repertoire/innovation/
- Social innovation: https://pportela1980.github.io/networks/relational-repertoire/social-innovation/
- Long-term care: https://pportela1980.github.io/networks/relational-repertoire/care/
- Civil protection: https://pportela1980.github.io/networks/relational-repertoire/civil-protection/
- Entry page: https://pportela1980.github.io/networks/relational-repertoire/

All actors, accounts and outcomes are fictional. Links and positions are curated illustrations, not outputs of a validated predictive model. The care case illustrates coordination, not clinical guidance, and contains no private medical records. The demos require no API keys or external scripts.

Institutional inspiration for the first two cases: ANI CoLAB (https://ani.pt/rede-colab/) and the supplied ALC listening report/public Urdaibai platform (https://urdaibai.agirrecenter.eus/). The original report is not included.

The civil-protection case is fictional, inspired by public context around storm Kristin. It is not a reconstruction of actual operations or an emergency procedure.
